# Class IX English — Board Practice Paper

An interactive, responsive practice paper for Class IX English based on the first six chapter themes and the poems **“The Daffodils”** and **“A Child's Invocation.”**

## Features
- Board-style sections and suggested 3-hour timer
- 20 textbook/general MCQs and 15 grammar MCQs with automatic checking
- Text-answer areas for textbook questions, poetry, essay or application
- Progress saved in the browser while you work
- Print-friendly layout and restart option
- Mobile-friendly design; no build step or external dependencies

## Run it
Open `index.html` in a browser, or enable GitHub Pages for this repository and use the deployed site URL.

## Note
This is an original practice paper for revision, not an official board-issued paper. Written responses are not automatically graded. Confirm the exact syllabus and format with your teacher or current board instructions.
